Upload de imagens pro blog

Guia de referência do scripts/upload-image.mjs: como trocar a foto de capa de um post e como subir fotos soltas (produto, imagem dentro do texto) pro bucket azpetshop-images, servido em cdn.azpetshop.com.br.

Visão geral

O caminho que a imagem percorre

Não existe um botão "upload" num site — o script faz os quatro passos abaixo de uma vez, no seu terminal.

01 Arquivo no seu PC rottweiler.jpg
→
02 upload-image.mjs escolhe a key e chama o wrangler
→
03 Bucket R2 azpetshop-images
→
04 CDN público cdn.azpetshop.com.br/…

Se for a capa do post, o script ainda faz um quinto passo: reescreve a linha hero: do .mdx pra apontar pra URL nova. Se for uma imagem solta, ele te devolve o link pra você colar onde quiser no texto.

Preparo

Antes de começar

  • Rodar os comandos sempre dentro da pasta do projeto (c:\Projetos\azpetshop).
  • Autenticar o wrangler uma única vez por máquina — se já rodou wrangler login antes, pode pular isso.
  • Ter a imagem já no formato final (o script não redimensiona nem comprime — sobe o arquivo como está).
Terminal — só na primeira vez
$ npx wrangler login
# abre o navegador, você confirma o login na Cloudflare, pronto
Formatos aceitos

.jpg, .jpeg, .png, .webp, .gif e .svg. Qualquer outra extensão o script recusa antes de subir.

Vocabulário

Bucket, key e URL — o que é cada coisa

Três termos aparecem em toda saída do script. Vale entender pra ler os resultados sem susto:

TermoO que éExemplo
Bucket O espaço de armazenamento na nuvem — como uma pasta raiz. Já existe, é sempre o mesmo. azpetshop-images
Key O caminho do arquivo dentro do bucket. O script monta essa key pra você. posts/caes/rottweiler/hero.jpg
URL pública Bucket + key, servidos pelo domínio que conectamos ao R2. É o que vai no .mdx. cdn.azpetshop.com.br/posts/caes/rottweiler/hero.jpg

Cenário 1 — Trocar a capa de um post

Quando: você tem uma foto nova pro hero: do post (a imagem grande que aparece no topo e nas listagens).

  1. Descubra o "post id" do artigo É categoria/slug — o mesmo caminho da URL do post. Pra src/content/blog/caes/rottweiler.mdx, o id é caes/rottweiler.
  2. Rode o comando com --hero
    Terminal 
    $ node scripts/upload-image.mjs --post caes/rottweiler --file ./rottweiler.jpg --hero --alt "Rottweiler deitado no jardim"

Subindo ./rottweiler.jpg -> azpetshop-images/posts/caes/rottweiler/hero.jpg ...
Upload complete.

✅ hero de "caes/rottweiler" atualizado para:
https://cdn.azpetshop.com.br/posts/caes/rottweiler/hero.jpg
  3. Confira o .mdx — já está atualizado O script troca a linha hero: (e cria ou atualiza o heroAlt:, se você passou --alt). Nada mais no arquivo muda.
    category: "caes"
    type: "guia"
    hero: "https://www.azpetshop.com.br/img/news/rottweiler_1_600.jpg"
    hero: "https://cdn.azpetshop.com.br/posts/caes/rottweiler/hero.jpg"
    heroAlt: "Rottweiler deitado no jardim"
    publishedAt: 2026-06-30
  4. Confira o resultado e suba pro git Rode npm run dev se quiser ver o post localmente antes, depois git add + commit do .mdx como qualquer outra mudança de conteúdo.
Atenção

Rodar --hero de novo pro mesmo post sobrescreve o arquivo hero.jpg anterior no bucket — não fica lixo acumulado, mas também não tem "desfazer" além do git checkout no .mdx pra voltar a URL antiga (a imagem antiga só continua acessível se você não tiver sobrescrito a key dela).

Cenário 2 — Subir uma imagem solta

Quando: foto de um produto recomendado, ou qualquer imagem que vai dentro do corpo do post — não a capa.

  1. Rode sem --hero, com um --name O --name vira o nome do arquivo lá no bucket — escolha algo que descreva a imagem.
    Terminal 
    $ node scripts/upload-image.mjs --post caes/rottweiler --file ./racao-x.jpg --alt "Ração X para cães adultos" --name racao-x

Subindo ./racao-x.jpg -> azpetshop-images/posts/caes/rottweiler/racao-x.jpg ...
Upload complete.

✅ Upload concluído: https://cdn.azpetshop.com.br/posts/caes/rottweiler/racao-x.jpg

Cole isso onde quiser no corpo do post:
![Ração X para cães adultos](https://cdn.azpetshop.com.br/posts/caes/rottweiler/racao-x.jpg)
  2. Cole a linha final no .mdx Abra o arquivo do post e cole o ![alt](url) que o script imprimiu, no ponto do texto onde a imagem deve aparecer — igual às fotos de produto que já existem nos posts de comparativo (tipo melhores-antipulgas-cachorros.mdx).
  3. Sem --name? O script usa o nome do arquivo original, convertido pra minúsculo e sem espaços/acentos — funciona, mas um nome escolhido por você fica mais fácil de reconhecer depois.

Referência

Todas as flags

FlagObrigatóriaO que faz
--postSimId do post — categoria/slug, igual ao caminho do arquivo em src/content/blog.
--fileSimCaminho da imagem no seu computador.
--heroNãoMarca esta imagem como a capa do post e atualiza o hero: no .mdx automaticamente.
--altRecomendadaTexto alternativo — vira heroAlt: (no modo capa) ou o texto do Markdown ![alt](url) (no modo solto).
--nameNãoNome do arquivo no bucket, sem extensão. Ignorada no modo --hero (que sempre usa hero).

Organização

Convenção de pastas no bucket

O script já monta isso sozinho — mas ajuda saber o padrão pra reconhecer as keys depois:

Estrutura
posts/<categoria>/<slug>/hero.jpg       # capa do post
posts/<categoria>/<slug>/<nome>.jpg     # imagens soltas do mesmo post

Assim todas as imagens de um post ficam juntas, e o nome da categoria/slug já entrega de qual artigo é cada foto sem precisar abrir o bucket pra descobrir.

Quando algo dá errado

Erros comuns

MensagemCausaComo resolver
post não encontrado: … O valor de --post não bate com nenhum arquivo em src/content/blog. Confira categoria e slug exatos — sem .mdx no final, sem barra no começo.
extensão não suportada O arquivo em --file não é .jpg, .jpeg, .png, .webp, .gif ou .svg. Converta a imagem pra um desses formatos antes de subir.
You are not authenticated O wrangler nunca fez login nesta máquina, ou o login expirou. Rode npx wrangler login de novo e repita o upload.
Comando trava ou não abre navegador Acontece só no wrangler login, não no upload em si. Copie o link impresso no terminal e abra manualmente no navegador.

Cola rápida

Os dois comandos, prontos pra editar

Troque caes/rottweiler, o caminho do arquivo e o texto alternativo pelos seus dados.

Capa do post 
$ node scripts/upload-image.mjs --post caes/rottweiler --file ./foto.jpg --hero --alt "descrição da foto"
Imagem solta
